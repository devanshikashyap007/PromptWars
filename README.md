# StadiumFlow AI | Premium Event Companion

StadiumFlow AI is a high-performance web dashboard designed to optimize the attendee experience at large-scale sporting venues. Built with premium aesthetics and real-time simulation logic, it addresses challenges like crowd movement, waiting times, and navigation.

## 🚀 Live Demo
[https://stadiumflow-ai-wudqphm6za-uc.a.run.app](https://stadiumflow-ai-wudqphm6za-uc.a.run.app)

## ✨ Features
- **Live Density Map**: Real-time crowd flow visualization using SVG heatmaps.
- **Smart Queue Tracker**: Estimated wait times for concessions and restrooms with color-coded status.
- **Seat Finder Interaction**: Animated navigation path from entrance to seat.
- **Micro-interactions**: Pulse effects, hover transitions, and haptic-style feedback.
- **Premium Design**: Light mode with glassmorphism, soft shadows, and custom typography (Outfit).

## 🛠️ Tech Stack
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism), Vanilla JavaScript.
- **Backend**: Node.js & Express (used for production serving).
- **Deployment**: Google Cloud Run.
- **Design**: AI-generated architectural stadium assets.

## 📦 Installation & Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/devanshikashyap007/PromptWars.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the server:
   ```bash
   npm start
   ```
